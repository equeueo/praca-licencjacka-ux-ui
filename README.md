# Strona internetowa wspierająca naukę języków obcych

Projekt pracy licencjackiej przedstawiający autorski interfejs UX/UI strony internetowej wspierającej naukę języków obcych.

Projekt został opracowany z uwzględnieniem 10 heurystyk użyteczności Jakoba Nielsena. W ramach pracy przygotowano architekturę informacji, makiety oraz interaktywny prototyp interfejsu w programie Figma.
